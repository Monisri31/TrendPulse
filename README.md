# TrendPulse: What's Actually Trending Right Now?

## Project Overview

TrendPulse is a data analysis project that explores trending video records across the United States (US), Great Britain (GB), and India (IN).

The project uses Python, NumPy, Pandas, Matplotlib, Seaborn, Plotly, MySQL, and Microsoft Excel to clean, analyze, visualize, and interpret data.

**Note:** The supplied dataset is synthetic and intended for educational purposes. The findings do not represent actual YouTube trends.
